# v1.5.0 Release Notes - Performance & Motion Overhaul

Release Date: March 24, 2026
Build: v1.5.0 (Draft)
Previous Version: v1.4.0

---

## Overview

v1.5.0 is focused on making Pulse Music feel modern, responsive, and smooth in daily use.
This release targets the pain points reported after v1.4.0:
- slow startup feel
- laggy screen transitions between scenes (Songs, Albums, Artists, Settings, Queue, and more)
- heavy-feeling Now Playing updates
- stutter while scrolling Settings
- delayed track switching responsiveness

---

## New in v1.5.0

### Startup and Load-Time Improvements

- Deferred initial media scanning for better first frame speed.
- Removed unconditional startup scan on every app open.
- App now scans automatically only when library data is empty.
- Added a short startup defer before scan trigger to avoid blocking perceived launch smoothness.

Files:
- app/src/main/java/com/suspended/music/MainActivity.kt

### Faster Track Switching and Playback Start

- Optimized song tap handling to avoid synchronous full-library database fetch on every tap.
- Reused already-available in-memory sorted list for immediate playback queue resolution.
- Added DB fallback only when in-memory cache is missing selected track.
- Moved play count increment work to IO dispatcher to reduce UI thread pressure.

Files:
- app/src/main/java/com/suspended/music/ui/viewmodel/MainViewModel.kt

### Songs Screen Performance Refactor

- Replaced full in-memory song list rendering with Paging-backed rendering path.
- Completely removed the unoptimized Grid View to enforce a single, ultra-fast List View layout, drastically reducing UI complexity.
- Eliminated severe scrolling jank and over-recomposition by stripping `peek()` out of the Paging 3 Compose item keys, allowing Compose to natively and efficiently handle lazy item tracking.
- Switched Songs list to consume paged data for better scaling on large libraries.
- Kept stable item keys/content types in lazy containers for smoother recycling and scroll behavior.
- Tuned song list/grid image pipeline by removing transition crossfades and tightening decode targets.
- Updated cache key strategy for Songs list/grid thumbnails to reduce redundant decoding churn.
- Added adaptive thumbnail decode sizes based on list density and grid columns.
- Lowered image sampling/filter cost in Songs list/grid rendering path.
- Added debug-only recomposition tracing guards in Songs route with an explicit hard-off switch for production safety.
- Prioritized responsiveness and consistency over decorative animation.

Files:
- app/src/main/java/com/suspended/music/ui/screens/SongsScreen.kt
- app/src/main/java/com/suspended/music/ui/components/MusicComponents.kt

### Baseline Profile Setup (Optional, Ready)

- Added profile installer runtime dependency so baseline profiles are applied on user devices.
- Added initial baseline profile rules file targeting startup/navigation/songs hot paths.
- This scaffolds the project for future Macrobenchmark-driven profile generation without blocking current builds.

Files:
- app/build.gradle.kts
- gradle/libs.versions.toml
- app/src/main/baseline-prof.txt

### Now Playing Smoothness

- Reduced heavy whole-screen recompositions while playback position updates.
- Isolated timeline/progress updates into a dedicated timeline composable.
- Kept high-frequency position updates from forcing expensive static UI redraws.

Files:
- app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

### Mini Player Efficiency

- Memoized mini-player album art image requests.
- Prevented request recreation on each progress tick.

Files:
- app/src/main/java/com/suspended/music/ui/components/MiniPlayer.kt

### Navigation and Scene Transition Overhaul

- Globally slashed scene transition durations from 300ms/200ms down to a highly optimized 150ms/100ms for instantaneous-feeling navigation.
- Replaced heavier spring+scale global route animation with lighter motion.
- Added smoother fade + subtle horizontal slide for normal scene navigation.
- Added dedicated fast fade transitions for bottom-tab route switches.
- Tuned Now Playing sheet-style vertical transition timing for a cleaner open/close feel.

Impacted scenes:
- Home
- Songs
- Albums
- Artists
- Playlists
- Playlist Detail
- Search
- Settings
- Queue
- Equalizer
- Tag Editor
- Now Playing

Files:
- app/src/main/java/com/suspended/music/ui/navigation/MusicNavHost.kt
- app/src/main/java/com/suspended/music/ui/navigation/AnimatedNavigation.kt

### Material 3 UI Standardization & Now Playing Overhaul

- Completely eliminated experimental/expressive colors (`surfaceContainer`, etc.) in favor of standard Material 3 semantic properties (`surface`, `surfaceVariant`), fixing previous unresolved references.
- Removed the isolated `NpPalette` from Now Playing, actively binding all player view boundaries directly into `MaterialTheme.colorScheme` for native theme tracking.
- Polished the Now Playing screen's play button and crossfade pipelines by dropping heavy `spring` effects for ultra-light `tween(150)` animations. 
- Resolved multiple icon deprecation warnings by cleanly shifting to `Icons.AutoMirrored.Filled`.

### In-App Update Engine (GitHub API)

- Massively upgraded `GitHubApi.kt` to natively enforce strict `Accept: application/vnd.github.v3+json` headers, ensuring secure GitHub API integration.
- Wired robust `assets[]` JSON deserialization (`GitHubAsset`) mapped to a new `apkAsset` helper property, automatically locating direct `.apk` binary downloads in the release channels.
- Interfaced a `getAllReleases()` query structure preparing the settings for future Beta/Pre-release opt-in tracking.

Files:
- app/src/main/java/com/suspended/music/data/api/GitHubApi.kt

### Settings Scrolling and Rendering Optimization

- Switched Settings app bar scroll behavior to pinned to reduce nested-scroll overhead.
- Hoisted playback/scan flows to top-level collection to reduce repeated collector setup.
- Reduced per-frame work in theme color picker by replacing repeated runtime color parsing with remembered static color values.
- Reused horizontal scroll state for color swatches.

Files:
- app/src/main/java/com/suspended/music/ui/screens/SettingsScreen.kt

### Playback Polling Balance

- Tuned foreground playback position polling cadence from 500ms to 650ms.
- Reduced update churn and CPU pressure while maintaining smooth timeline updates.

Files:
- app/src/main/java/com/suspended/music/ui/viewmodel/MainViewModel.kt

### Post-Audit Performance, UI & UX Fixes

Applied: April 1, 2026

#### Critical Performance Fixes

1. **AlbumsScreen lifecycle-aware state collection** — Replaced `collectAsState()` with `collectAsStateWithLifecycle()` to stop background state collection and prevent unnecessary CPU/battery drain when the app is backgrounded. Also cleaned up duplicate `Icon`/`IconButton` imports.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/AlbumsScreen.kt

2. **NowPlayingScreen palette memoization** — Wrapped `NpPalette` construction in `remember(scheme)` so the palette object is only rebuilt when the color scheme actually changes, eliminating garbage allocation every ~650ms during playback.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

3. **NowPlayingScreen album art ImageRequest caching** — Memoized the Coil `ImageRequest` with `remember(song.id)`, added explicit size constraints (520px), and added memory/disk cache keys to prevent request rebuilds during recompositions.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

4. **Theme container color derivation** — Fixed `primaryContainer`, `secondaryContainer`, and `tertiaryContainer` being set identical to their parent colors, which broke Material 3 tonal contrast on non-dynamic-color devices. Container colors now use `compositeOver()` to derive proper lighter tonal variants.

   Files:
   - app/src/main/java/com/suspended/music/ui/theme/Theme.kt

#### Performance Improvements

5. **Shuffle All off main thread** — Moved the full-library shuffle from `HomeScreen` (which allocated a complete list copy on UI thread) into a new `MainViewModel.shuffleAndPlay()` function that performs the shuffle on `Dispatchers.Default`.

   Files:
   - app/src/main/java/com/suspended/music/ui/viewmodel/MainViewModel.kt
   - app/src/main/java/com/suspended/music/ui/screens/HomeScreen.kt

6. **SongsScreen double bottom padding fix** — Consolidated duplicated bottom-padding (100dp on modifier + scaffold bottom padding on contentPadding) into a single `contentPadding` value to eliminate excessive empty space at the end of the song list.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/SongsScreen.kt

12. **HomeScreen greeting memoization** — Cached the `getGreeting()` result with `remember` to avoid creating a new `Calendar` instance on every recomposition.

    Files:
    - app/src/main/java/com/suspended/music/ui/screens/HomeScreen.kt

13. **playSongs() DB write dispatching** — Moved `incrementPlayCount()` to `withContext(Dispatchers.IO)` inside the existing coroutine scope for proper dispatcher usage.

    Files:
    - app/src/main/java/com/suspended/music/ui/viewmodel/MainViewModel.kt

#### UX Fixes

7. **NowPlayingScreen "Add to Playlist" button wired up** — The "Add to Playlist" icon button previously only triggered haptic feedback. It now opens a `PlaylistPickerDialog` allowing the user to add the current song to any editable playlist.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

8. **NowPlayingScreen dead Volume button removed** — Removed the no-op volume button from the Now Playing top action row, which only triggered haptic feedback without performing any action.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

9. **NowPlayingScreen duplicate Equalizer entry removed** — Removed the redundant "Equalizer" entry from the overflow dropdown menu since it's already accessible via the dedicated icon in the top action row.

   Files:
   - app/src/main/java/com/suspended/music/ui/screens/NowPlayingScreen.kt

10. **PlaylistsScreen "Create Playlist" FAB wired up** — The FAB was previously a no-op (`/* Show create playlist dialog */`). It now navigates to the `PlaylistsManagement` screen.

    Files:
    - app/src/main/java/com/suspended/music/ui/navigation/MusicNavHost.kt

11. **PlaylistsManagementScreen bottom padding + visibility fix** — Added 100dp bottom `contentPadding` to prevent the last playlist item from rendering behind the mini player. Made `PlaylistItem` composable `private` since it's screen-specific, allowing the Compose compiler to better optimize it.

    Files:
    - app/src/main/java/com/suspended/music/ui/screens/PlaylistsManagementScreen.kt

#### Code Hygiene

- Fixed missing `Icons` and `Icons.AutoMirrored.Filled.Sort` imports in `SongsScreen.kt` (pre-existing build error).
- Removed unused `VolumeUp` icon import from `NowPlayingScreen.kt`.
- Removed duplicate `Icon`/`IconButton` imports from `AlbumsScreen.kt`.
