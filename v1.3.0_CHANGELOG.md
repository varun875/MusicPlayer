# v1.3.0 Release Notes - Modernization & Customization Update

## 🚀 Key Highlights

Version 1.3.0 is a massive update focused on **User Customization**, **Smart Features**, and a complete **Technical Overhaul** of the codebase to the latest 2026 standards.

### ✨ New Smart Features
- **Favorites Playlist**: Auto-managed playlist for your liked songs. Includes logic to prevent accidental "unlike" actions.
- **Recently Played**: dedicated playlist tracking your listening history.
- **Improved Smart Logic**: Playlists now automatically update based on library changes.

### 🎨 UI Customization & Theming
- **Layout Control**:
  - **View Modes**: Toggle between **Grid** and **List** views for Albums, Artists, and Songs.
  - **Grid Size**: Customizable grid columns (2, 3, or 4 items wide) for Albums and Artists.
  - **List Density**: Toggle between **Normal** and **Compact** density for song lists to see more track info at a glance.
- **Persisted Settings**: All view preferences are saved globally in `DataStore` and remembered across app restarts.
- **Visuals**: Enhanced dynamic color extraction from album artwork using Palette API.
- **Navigation Animations**: Implemented smooth transition effects (Slide + Fade) between screens for a more polished user experience.
  - Standard navigation uses a horizontal slide/fade.
  - Now Playing screen uses a vertical slide up/down transition.

### 🏷️ Advanced Tag & Metadata Editor
- **Full Metadata Editing**:
  - Edit **Title**, **Artist**, **Album**, and **Genre** tags for any audio file.
  - Changes are written directly to the file (ID3v2 support).
- **Embedded Lyrics Editor**:
  - View and Edit unsynced lyrics embedded directly in the audio file.
- **Album Artwork Picker**:
  - Replace album covers by picking any image from your device gallery.
  - Artwork is permanently embedded into the audio file.

### 📱 Home Screen Widgets
- **Enhanced Music Widget**:
  - Added **Playback Progress Bar** to the home screen widget.
  - **State Preservation**: Widget remembers track duration and position even after process death.
  - Full playback controls (Play/Pause, Skip, Previous).

### 🛠️ Technical Modernization (The "Under the Hood" Overhaul)
We performed a major dependency upgrade to ensure stability, performance, and compatibility with upcoming Android versions.

#### 📦 Dependency Upgrades
- **Kotlin**: Updated to **2.1.10** (Latest stable K2 compiler).
- **Core KTX**: Updated to **1.15.0**.
- **Jetpack Compose**:
  - BOM updated to **2026.01.00**.
  - Lifecycle updated to **2.10.0** (Fixes state hoisting bugs).
- **Dependency Injection**:
  - **Hilt** updated to **2.55**.
- **Image Loading**:
  - Migrated from Coil 2.x to **Coil 3.3.0**.
  - Fixed `ImageLoaderFactory` and `MemoryCache` API changes.
- **Audio Engine**:
  - **Media3 (ExoPlayer)** updated to **1.9.1**.
- **Async & Data**:
  - **Coroutines** updated to **1.10.1** (Better Flow performance).
  - **DataStore** updated to **1.2.0**.
  - **Paging 3** updated to **3.3.6**.

#### 🔧 Build System Fixes
- Resolved `toml_syntax_error` in version catalog.
- Fixed Kotlin/KSP compatibility issues (`error.NonExistentClass`).
- Resolved `ImageLoader` context parameter type mismatches in DI modules.
- Clean build verified for `debug` build variant.
